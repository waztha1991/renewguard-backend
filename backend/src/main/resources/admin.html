SMTP email

Configure outbound email to send temporary passwords to agents. For Cloudflare Email Sending: host smtp.mx.cloudflare.net, port 465, username api_token, password = API token with Email Sending: Edit, from e.g. noreply@antsolutions.uk (domain must be onboarded under Email Service → Email Sending). The password is stored in SQLite and never returned after save — leave blank to keep it. Status: Not loaded

Cloudflare requires TLS on port 465 (SSL). Port 587 uses STARTTLS with other providers.

Backup

Download a ZIP containing a consistent SQLite snapshot (renewguard.db) and the uploads/ folder. SMTP credentials are included inside the database file — store backups securely.

Restore backup

Upload a previously downloaded backup ZIP. This replaces the live database and, when the ZIP includes uploads/, replaces the uploads folder for consistency. Before overwrite, the server keeps a timestamped safety copy (renewguard.db.pre-restore-…, and uploads.pre-restore-… when uploads are replaced).
